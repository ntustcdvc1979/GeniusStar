# 崇德機智星 — 個人搶答系統

一人一支手機的現場搶答遊戲。手機（直式）作答、主持人控制台、投影幕、題目後台。
前端純靜態，架在 GitHub Pages；即時同步用 Firebase Realtime Database。

架構、音樂、資料庫設定都沿用 [大學星攻略（cdfreshmen）](https://github.com/ntustcdvc1979/cdfreshmen)，
差別是**以個人為單位**：沒有分組、沒有上台代表與台下學員，每個人自己答、自己拿分。

| 頁面 | 網址 | 誰用 |
|---|---|---|
| 玩家端 | `https://ntustcdvc1979.github.io/GeniusStar/` | 每位玩家的手機 |
| 主持人控制台 | `.../host.html` | 主持人 |
| 投影幕 | `.../screen.html` | 投影機 |
| 題目後台 | `.../admin.html` | 出題的人 |
| 自我檢查 | `.../selftest.html` | 改過計分程式後開一下，看有沒有 FAIL |

## 一、遊戲怎麼玩

1. 玩家掃 QR Code，輸入**暱稱**就進場（一人一支手機）。投影幕的「掃碼加入」頁會即時冒出每個人的暱稱。
2. 主持人按「出題」→ 投影幕與手機同時開始**倒數**（預設 20 秒，控制台可改）。
3. 玩家在手機上選 A/B/C/D，按 **「確認送出」** 才算數 —— **送出後不能改**。
4. 投影幕顯示「已送出 N / M 人」與進度條，送出的人暱稱會亮起來（只顯示誰送了，不顯示選什麼；控制台可關）。
5. 倒數歸零自動截止（不會自動公布答案）。
6. 主持人按「公布答案」→ 投影幕出現正解、答案說明、**答對人數**與**最快答對的前五名**。
   玩家手機顯示自己對錯、作答秒數、**目前排名**。
7. 之後用 **→** / **←** 翻頁：

   ```
   答案與說明 → 補充說明（有填才有）→ 目前戰況（每 5 題才有，前 10 名）→ 全場作答分布
   ```

8. 全部跑完按「結束並公布排行榜」→ 投影幕按空白鍵依序公布 **第三名 → 第二名 → 第一名**（灑彩帶），
   再按一次回到主視覺收尾。玩家手機會看到前三名與自己的名次。

### 計分

| 條件 | 分數 |
|---|---|
| 答對 | +配分（預設 1，可逐題調整 1～99） |
| 答錯／沒答 | 0 |
| 正解設成「**都正確**」的題目 | 有送出就 +配分（選哪個都算對）；沒送出還是 0 |
| 被加倍轉盤抽中的人 | 下一題配分 ×2 |

**排名**：總分 → 答對題數 → **答對題目的作答時間加總**（越短越前面）。三項都一樣才並列。

- 作答時間 = 按下「確認送出」的伺服器時間 − 這題**第一次**出題的伺服器時間。
  兩個都是伺服器時間（資料庫規則強制），手機時鐘不準也不影響，也沒辦法造假。
- 主持人重新出同一題（例如按「← 上一題」）時，已經送出的人時間不會被重算成 0 秒。
  要整題重來請用「清除本題作答」。
- **都正確**：後台正解可以選「都正確」，那一題沒有人會錯 —— 適合「你最喜歡哪一個？」這種沒有標準答案的題目，
  或是想送分的時候。公布時投影幕與手機的大字會顯示「都正確」，四條長條全部是綠色。
  注意**沒送出的人還是 0 分**，作答時間也照算（同分時一樣比速度）。
- **DEMO 題庫完全不計分**，可以拿來暖場。

**加倍轉盤**：主持人按「轉一次」，投影幕轉出一位玩家，他的下一題答對分數 ×2。
抽過的人不會再被抽到（全部抽完才重新一輪）。人多的時候轉盤只畫 20 格（中獎者一定在裡面），
不然字會小到看不見。抽中的人手機上會看到通知。

## 二、上線前要做的事

### 1. 把 Firebase 設定放進 GitHub Secret

跟 cdfreshmen **用同一個 Firebase 專案**，所以設定值也一樣：

GitHub repo（GeniusStar）→ **Settings → Secrets and variables → Actions → New repository secret**：

- Name：`FIREBASE_CONFIG`
- Secret：跟 cdfreshmen 那個 secret 一模一樣的 JSON（一行，要含 `databaseURL`）

本機測試：`assets/js/firebase-config.js` 已經從 cdfreshmen 複製過來了（不進版控）。

### 2. 更新資料庫安全性規則 ⚠️ 最重要

兩套系統共用同一個資料庫，所以**規則也是同一份**。GeniusStar 的資料全部放在 `/gs` 底下，
跟大學星攻略的 `/state`、`/questions`… 完全分開，互不干擾。

Firebase 主控台 → **Realtime Database → 規則**，把這個 repo 的
[`database.rules.json`](database.rules.json) **整份**貼上並發布。

這份檔案 = cdfreshmen 原本的規則（一字未改）＋ 新的 `gs` 區段，所以貼上去大學星攻略照常運作。
**之後如果改了 cdfreshmen 的規則，記得兩邊的檔案要同步**，不然後貼的那一份會把另一份蓋掉。

`gs` 區段做到：

- **正解不會外流**：`/gs/answerKey/{題號}` 只有公布後才讀得到。
- **截止後不能補答**：只有 `phase === "open"` 且題號相符時才寫得進去。
- **送出就定案**：同一題不能改第二次；被移出名單的人不能作答。
- **時間不能造假**：作答時間 `t` 必須是伺服器時間。
- **只能寫自己的**：每個人只能寫自己的暱稱與答案，也只讀得到自己的答案。
- **只有 `/admins` 名單上的 UID** 能出題、改狀態、看全場作答。

### 3. 登入與主持人名單 —— 不用再設定

Google 登入、匿名登入、授權網域（`ntustcdvc1979.github.io`）、`/admins` 白名單**全部跟 cdfreshmen 共用**，
已經設好就不用再動。能開大學星攻略控制台的人，這裡也能開。

### 4. 開啟 GitHub Pages

GitHub repo → **Settings → Pages** → Source 選 **`GitHub Actions`**。之後每次 push 到 `main` 會自動部署。

## 三、活動前準備

1. 開 `admin.html` 登入。
2. **開場畫面**（選填，留空就用內建的）：主視覺圖、開場影片、規則頁的圖。
3. **題目**：選「正式 / DEMO」題庫，新增題目。每題可以填題幹、A～D、正解（A～D 或「都正確」）、配分、
   說明排版（小標題／文字／圖片／影片）、整頁大圖或影片、說明音檔 —— 跟大學星攻略的後台一模一樣。
   **隱藏（備用題）**：題目列表每題都有「🙈 隱藏」，編輯器裡也有勾選框。
   隱藏的題目會留在後台（淡色虛線框、標「備用」），但**控制台選不到、不佔題號、不計分**，
   想用的時候按「👁 取消隱藏」就會照原本的順序回來。
4. 也可以用「批次貼上」一次匯入，一行一題：

   ```
   題幹 | A選項 | B選項 | C選項 | D選項 | 正解
   ```

   正解填 `A`～`D` 或 `都正確`。只有兩個選項就少寫兩欄：`題幹|甲|乙|B`。

5. 圖片放 `assets/img/explain/`（一律 `.webp`），影片放 `assets/video/`，音檔放 `assets/audio/`。
6. **先用 DEMO 題庫實際跑一輪**。
7. 測完到 `host.html` 按 **「清除所有作答紀錄」** 和 **「清空玩家名單」**。

## 四、現場操作

### 主持人控制台 `host.html`（整場都要開著，自動截止是它負責的）

| 按鈕 | 做什麼 |
|---|---|
| **題庫** | 切換正式 / DEMO |
| **▶ 出題／開始倒數** | 推題目給所有人 |
| **■ 提前截止** | 不等倒數結束就鎖住，不公布答案 |
| **🎉 公布答案** | 算好統計、解鎖正解、更新排行榜（玩家手機上的名次跟著更新） |
| **下一題 →** | 直接出下一題並開始倒數 |
| **🏆 結束並公布排行榜** | 產生最終排名 |
| **◀ 上一頁 / 下一頁 ▶** | 遠端翻投影幕，跟在投影機上按 ←／→ 一樣 |
| **🎡 轉一次 / 取消加倍** | 加倍轉盤 |
| **🔔 上／下課鐘聲、🤸 健康操** | 在投影幕放音檔，再按一次停止 |
| **⟲ 清除本題作答** | 這一題重來 |
| **⟲ 清除所有作答紀錄** | 清空答案、統計、排行榜（玩家名單保留） |
| **✕ 清空玩家名單** | 所有人回到輸入暱稱的畫面 |

控制台還看得到：作答分布、**答對最快的人**（只有主持人看得到）、即時排行榜（前 30 名）、
**玩家名單**（可搜尋，暱稱不恰當可以「移出」）。

### 投影幕 `screen.html`

待機時的開場頁，用 **→** / **←** 翻：

| 頁 | 內容 |
|---|---|
| 黑畫面 | 投影機先暖機，台下什麼都看不到 |
| 開場影片 | 後台有填才有這一頁 |
| 主視覺 | 後台的主視覺圖；沒填就是內建的「崇德機智星 GENIUS STAR」 |
| 遊戲規則 | 規則條列 + QR Code + 手機作答示意圖（用玩家端真正的樣式畫的） |
| 掃碼加入 | 大 QR Code + 已加入人數 + 所有人的暱稱，有人進場會發出報到音 |

- 第一次開要按「開啟音效」（瀏覽器規定），再按 **F11** 全螢幕。
- 要先在同一個瀏覽器開 `host.html` 登入過。

### 音樂與音效

完全沿用大學星攻略：作答 `bgm-quiz.mp3`、講解 `bgm-reveal.mp3`、排行榜 `bgm-final.mp3`、
轉盤 `bgm-wheel.mp3` + `wow.m4a`、公布答案 `sfx-reveal.mp3`、鐘聲 `bell.m4a`、健康操 `lucy.m4a`，
提示音（倒數、送出、報到、時間到）用 Web Audio 即時合成。
[`assets/js/sounds.js`](assets/js/sounds.js) 是直接從 cdfreshmen 複製的。

一百個人同時送出時，送出音效會自動節流，不會吵成一團。

## 六、資料庫結構（全部在 `/gs` 底下）

```
/admins/{uid}                 true                    ← 主持人白名單（跟 cdfreshmen 共用）
/gs/config/intro              { heroImg, video, rulesImg }
/gs/questions/{qid}           { order, text, a,b,c,d, list, pts, hidden, blocks, exImgFull, exAudio }
/gs/answerKey/{qid}           "A"～"D" 或 "都正確"    ← 公布後才讀得到
/gs/state                     { phase, list, qid, openedAt, limitSec, showNames, revealed:{qid:true},
                                pendingDouble, wheel:{id,uid}, cue:{id,kind}, nav:{id,dir}, screenPage }
/gs/players/{uid}             { name, at }
/gs/answers/{qid}/{uid}       { c, t }                ← 送出就定案，t 是伺服器時間
/gs/opened/{qid}              伺服器時間              ← 第一次出題的時間，作答秒數從這裡算
/gs/stats/{qid}               { A,B,C,D,total,key,correct,openedAt,fastest:[…] }
/gs/doubles/{qid}             uid                     ← 轉盤抽中、該題 ×2 的人
/gs/leaderboard               { updatedAt, final, questions, rows:[…] }
```

## 七、已知限制

- **Firebase 金鑰一定是公開的**，安全性靠資料庫規則 + `/admins` 白名單。
- 玩家身分綁在**那一支手機的瀏覽器**上。清掉瀏覽器資料或換手機，就要重新輸入暱稱（成績從零開始）。
- 暱稱不檢查重複；兩個人取一樣的名字，排行榜上就會出現兩個一樣的名字。
- 免費方案的 Realtime Database 同時連線上限 **100 人**。人數超過要升級 Blaze（按量計費，這種規模幾乎不會產生費用）。
  注意這個上限是**整個資料庫**算的 —— 如果兩套系統同時在用，人數會加在一起。
- 主持人登入用 Google 彈出視窗，請用電腦版 Chrome / Edge 並允許彈出視窗。
